Высокопроизводительная SIMD-оптимизированная хеш-таблица на C для ARM (NEON), рассчитанная на максимальную скорость вставки и поиска для `uint64_t` и фиксированных строк.

---

## Бенчмарк (5,000,000 элементов)

| Операция       | FlatHashMap | std::unordered_map | Преимущество   |
|----------------|-------------|--------------------|----------------|
| u64 Вставка    | 0.123 сек   | 1.515 сек          | 12.32x быстрее |
| u64 Поиск      | 0.283 сек   | 0.369 сек          | 1.30x быстрее  |
| String Вставка | 0.401 сек   | 1.734 сек          | 4.32x быстрее  |
| String Поиск   | 0.919 сек   | 1.310 сек          | 1.43x быстрее  |

---

## Ключевые особенности

- ARM NEON SIMD-ускорение (обработка 16 control-элементов за один проход)
- Block-based open addressing (пробирование группами по 16 слотов)
- Linear probing с фиксированным шагом GROUP_SIZE 
- FNV-1a 64-bit хеширование для стабильного распределения ключей
- 7-битный fingerprint + EMPTY marker (0x80) для быстрого предварительного фильтра
- SIMD-фильтрация кандидатов перед точным сравнением ключей/строк
- 16-byte aligned memory layout (aligned_alloc) для эффективных NEON-load операций
- Раздельные реализации для uint64_t и fixed-size string keys
- Минимальный low-level API без лишних абстракций и runtime overhead

## Запуск:
make

## Использование:
u64
fhm_u64 *m = fhm_u64_create(1024);
fhm_u64_put(m, 42, 100);

uint64_t v;
fhm_u64_get(m, 42, &v);

fhm_u64_free(m);
string
fhm_str *m = fhm_str_create(1024);
fhm_str_put(m, "key", 777);

uint64_t v;
fhm_str_get(m, "key", &v);

fhm_str_free(m);
